    Setup

    Three steps, about two minutes.

    1

    Install and Allow Access

    Drag LilUsage to Applications and open it. Click the meter in the menu bar and read the short intro first: it tells you about the Keychain prompt before macOS shows it.

    2

    Sign In to Claude Code and allow access

    Run claude in a terminal, then /login. If you already use it, you're done here.

    If macOS asks for your Claude Code credentials, choose Always Allow. It won’t ask again.

    3

    Read the Meter

    The bar fills within seconds. If it ever says Sign in, your Claude Code session expired — the app walks you through it.

    Good to Know

    Why does it need Claude Code?

    The usage numbers come from an endpoint that only accepts the token Claude Code keeps on your Mac. LilUsage borrows that one instead of asking you to sign in again.

    Does it see my conversations?

    No. One credential, one request, percentages back. Nothing reaches the developer.

    Why not on the Mac App Store?

    Sandboxed apps can't read Claude Code's credentials, so LilUsage ships as a signed, notarized direct download.

    LilUsage is an independent utility, not affiliated with or endorsed by Anthropic. The usage endpoint it reads is undocumented and may change without notice.
