First-Time Setup

About two minutes, most of it downloading.

1

Sign In to Claude Code

LilUsage reads the login Claude Code already keeps on your Mac. If you use the claude command, you're set. If not, install it with npm install -g @anthropic-ai/claude-code, run claude, then /login.

A Claude subscription is what creates the usage figures in the first place — LilUsage just displays them.

2

Install LilUsage

Open the downloaded DMG and drag LilUsage to your Applications folder.

3

Open the App

Double-click to launch. macOS will show a security prompt the first time — click Open to continue. There's no window and no dock icon; look for the meter at the top right of your screen.

4

Allow Access to Your Claude Login

On first run, LilUsage explains what it's about to ask for, then macOS requests access to your stored Claude Code credentials. Choose Always Allow — otherwise the prompt returns every few minutes.

Keychain — reads the token Claude Code already stored
Network — one HTTPS call to Anthropic, every 30 seconds

Nothing else is touched, and nothing is ever sent anywhere else.

5

Read the Meter

The bar fills within a few seconds. Click it to open the panel with your session and weekly windows, each with a countdown to its reset.

The … button in the corner of the panel holds everything else:

Show Percentage — put the number beside the bar, or keep it bar-only
Launch at Login — start LilUsage when your Mac boots
Refresh Now — skip the wait for the next poll
How It Works — replay the first-run explainer any time
Quit — close the app

Seeing "Reconnect"? Your Claude Code session expired. Run claude once in a terminal and LilUsage picks up the new login on its own within a couple of seconds.

Good to Know

The honest fine print, before you download.

Why does it need Claude Code?

The usage figures come from an Anthropic endpoint that only accepts the session token Claude Code caches on your Mac. A third-party app can't obtain one on its own, so LilUsage borrows the one that's already there rather than asking you to sign in again.

Does it see my conversations?

No. It reads one credential and calls one endpoint that returns percentages. Your prompts, projects and files are never touched, and no data reaches the developer.

Why does it say Reconnect?

Claude Code sessions expire after a while. Run claude once and LilUsage detects the fresh login automatically — no restart, no re-approval.

Why not on the Mac App Store?

App Store apps run sandboxed, and a sandboxed app can't reach the credentials Claude Code stores. So LilUsage ships as a signed, notarized direct download instead.

How often does it refresh?

Every 30 seconds, with backoff if the endpoint pushes back. The countdown updates every second locally, so the panel feels live without extra requests.

LilUsage is an independent utility. It is not affiliated with, endorsed by, or sponsored by Anthropic. The usage endpoint it reads is undocumented and may change or stop working without notice.
