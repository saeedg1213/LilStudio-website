Privacy Policy

LilSnap for macOS — last updated 30 October 2026

LilSnap collects nothing. No personal data, no usage data, no analytics, no crash reports, no identifiers. The app has no server, no account system, and no network access at all: it ships without the network entitlement, so macOS won't let it connect to the internet.

What LilSnap stores on your Mac

LilSnap saves your settings (gaps, drag and Snap Bar options, keyboard shortcuts, your custom layouts, apps you asked it to ignore, and whether you finished the welcome screens) locally on your Mac using the standard macOS preferences system. It also counts how many layouts you've used, only to decide when to show Apple's own "rate this app" prompt. Ignored apps are stored as app identifiers such as com.apple.Safari. None of this leaves your computer. Deleting the app removes it.

How LilSnap sees your windows

To know where a window is, LilSnap asks macOS for the list of on-screen windows: each window's number, position, size, layer and which app it belongs to. It never reads window titles or contents, and it doesn't use Screen Recording. This list is read when you snap a window, drag one, switch apps (to update the menu bar icon) or open the menu, and it is never stored.

How LilSnap moves windows

LilSnap doesn't use Accessibility. When you snap a window, it sends one request to Apple's Shortcuts app (through Shortcuts Events) to run the LilSnap shortcut you added during setup. The request contains only numbers: where the window is now and where it should go. The shortcut uses Apple's own Find Windows, Move Window and Resize Window actions and runs entirely on your Mac. macOS asks your permission once before LilSnap can do this, and you can turn it off in System Settings → Privacy & Security → Automation.

Keyboard shortcuts and dragging

LilSnap registers only its own keyboard shortcuts with macOS, so it is told when you press one of them and nothing else. It never sees other keys or what you type, and it doesn't use Input Monitoring. For drag-to-snap, it is told when the mouse button goes down, moves and comes back up, so it can show the snap preview. The pointer position is used in the moment and never stored. You can turn drag-to-snap off in Settings.

Apps you choose from the Applications folder

When you add an app to the ignore list in Settings → Apps using the app picker, LilSnap reads that app's identifier from the bundle you selected. It reads nothing else and keeps no access to the file afterwards.

Automation

LilSnap's Shortcuts actions and lilsnap:// links only move windows or open LilSnap's settings, on your Mac.

What LilSnap does not do

  • It does not use Accessibility, Screen Recording or Input Monitoring.
  • It does not record, capture, or photograph your screen.
  • It does not read window titles, window contents, or anything you type.
  • It does not control any app other than Shortcuts Events, and only to run its own shortcut.
  • It does not connect to the internet.
  • It does not include third-party SDKs, trackers, or advertising.
  • It does not start at login unless you turn that on.

Children

LilSnap is suitable for all ages and collects no data from anyone, including children under 13.

Changes to this policy
